# MIRA — AI-ассистент для 3D-визуализатора

**MIRA — Message Intelligence & Response Assistant**  
*Интеллектуальный ассистент для анализа клиентской переписки и подготовки ответов.*

> **MIRA помогает ничего не потерять между сообщением клиента и готовой работой.**

MIRA — дипломный проект и разрабатываемый программный продукт для работы
3D-визуализатора с профессиональной перепиской.

Ассистент анализирует сообщения вместе с контекстом диалога, помогает выделять
задачи, правки, сроки, договорённости, вопросы оплаты и другие важные события
проекта.

## Основная задача

В реальной работе информация по одному проекту может находиться в десятках
сообщений: клиент присылает правки, уточняет материалы, меняет сроки,
согласовывает результат или возвращается к предыдущей договорённости.

Цель MIRA — преобразовывать такую переписку в структурированное состояние
проекта и помогать дизайнеру контролировать работу.

## Что уже реализовано

- анализ текста сообщений;
- определение смысловых категорий сообщений;
- определение нескольких категорий в одном сообщении;
- определение задач, требований и договорённостей;
- работа со сроками и событиями;
- отдельный анализ конфликтных ситуаций;
- хранение истории переписки;
- постоянное хранение диалогов в SQLite;
- учёт контекста предыдущих сообщений;
- раздельное состояние нескольких проектов;
- история изменений состояния проекта;
- система напоминаний;
- гибридный анализ: программные правила и предварительно обученная
  русскоязычная модель RuBERT;
- контекстная многометочная модель RuBERT на этапе разработки и проверки.

## Принцип работы

    Сообщение
        ↓
    Контекст диалога
        ↓
    Анализ сообщения
        ↓
    Задачи / правки / сроки / договорённости / оплата
        ↓
    Состояние проекта
        ↓
    Рекомендация дизайнеру

MIRA не должна самостоятельно принимать важные решения за пользователя.
Изменение стоимости, подтверждение сроков и другие значимые действия
остаются под контролем дизайнера.

## Машинное обучение

В проекте используются предварительно обученные русскоязычные модели RuBERT.

Разработка включает:

- базовые модели для сравнения;
- смысловую классификацию сообщений;
- анализ с учётом контекста диалога;
- многометочную классификацию, когда одно сообщение может одновременно
  относиться к нескольким смысловым категориям;
- проверку моделей на данных, не использовавшихся для их обучения.

Обученные модели хранятся локально и не публикуются в репозитории.

## Конфиденциальность данных

Для разработки используются в том числе обезличенные примеры реальной
профессиональной переписки.

Реальные сообщения, рабочие датасеты, локальные базы данных и обученные
модели не публикуются в открытом репозитории.

## Статус проекта

MIRA находится в активной разработке.

Текущая цель — получить стабильную рабочую версию с анализом переписки,
контекстом диалога, поддержкой нескольких контактов и проектов,
контролем задач, сроков и важных договорённостей.
