# AI Assistant — классификатор сообщений клиентов

## Описание проекта

### AI Assistant — классификатор сообщений клиентов в сфере дизайна интерьера, моделирования светильников и других предметов интерьера и экстерьера и 3D-визуализации.


Основная задача модели на текущем этапе:

**Определить намерение клиента (intent) по текстовому сообщению.**

Пример:

Вход:

```
Можно поменять цвет стен в спальне?
```

Результат модели:

```
Категория: правки
Уверенность: 95%
```

# Формат датасета

Датасет хранится в формате CSV.

Основные столбцы:

| Столбец  | Описание              |
| -------- | --------------------- |
| text     | сообщение клиента     |
| intent   | категория сообщения   |
| response | пример ответа клиенту |

Пример:

| text                                        | intent              | response                                          |
| ------------------------------------------- | ------------------- | ------------------------------------------------- |
| Здравствуйте, хочу заказать дизайн квартиры | первичное_обращение | Добрый день! Давайте обсудим детали проекта       |
| Можно изменить цвет дивана?                 | правки              | Конечно, внесем изменения после уточнения деталей |
| Когда будут готовы визуализации?            | сроки               | Уточним текущий этап и сообщим дату готовности    |

# Категории сообщений

Текущие категории:

## 1. Первичное обращение

Новые клиенты, которые хотят начать сотрудничество.

Примеры:

* Хочу заказать дизайн квартиры
* Интересует 3D визуализация
* Можно обсудить проект?

---

## 2. Стоимость

Вопросы о цене и расчете проекта.

Примеры:

* Сколько стоит дизайн?
* Какая стоимость визуализации?
* Как рассчитывается цена?

---

## 3. Оплата

Вопросы о способах и условиях оплаты.

Примеры:

* Как происходит оплата?
* Можно оплатить частями?
* Когда нужна предоплата?

---

## 4. Сроки

Вопросы о времени выполнения работы.

Примеры:

* Когда будет готов проект?
* Сколько занимает визуализация?
* Когда отправите рендеры?

---

## 5. Материалы

Запросы по исходным данным и материалам.

Примеры:

* Какие размеры нужны?
* Нужно ли отправлять план квартиры?
* Какие файлы предоставить?

---

## 6. Правки

Изменения в готовой или текущей работе.

Примеры:

* Нужно поменять цвет стен
* Можно изменить мебель?
* Давайте переделаем этот вариант

---

## 7. Рендеры

Запросы визуализации и изображений.

Примеры:

* Когда будут картинки?
* Можно посмотреть визуализацию?
* Отправьте финальные рендеры

---

## 8. Технический вопрос

Вопросы по файлам, программам и техническим моментам.

Примеры:

* В каком формате отправите файл?
* Можно открыть проект в другой программе?
* Какие требования к исходникам?

---

## 9. Благодарность

Положительная обратная связь.

Примеры:

* Спасибо, все отлично
* Очень красиво получилось
* Мне нравится результат

---

## 10. Конфликты (новая категория)

Ситуации недовольства клиента или сложных переговоров.

Примеры:

* Почему так долго?
* Я недоволен результатом
* Мы договаривались по-другому
* Меня не устраивает этот вариант
* Почему стоимость изменилась?

Цель категории:

Научить модель распознавать напряженные ситуации и в будущем предлагать корректную стратегию ответа.

# Правила подготовки данных

## Требования к сообщениям

Каждое сообщение должно:

* быть похоже на реальное сообщение клиента;
* иметь только одну категорию;
* содержать разные варианты формулировок.

---

# Требования к количеству данных

Для качественного обучения желательно:

Минимум:

```
100 сообщений на каждую категорию
```

Хороший вариант:

```
300-500 сообщений на категорию
```

Особое внимание уделить:

* правкам;
* рендерам;
* срокам;
* конфликтам.

Эти категории чаще всего имеют похожие формулировки.

---

# Правила создания ответов

Столбец `response` должен содержать пример профессионального ответа дизайнера.

Ответ должен быть:

* спокойным;
* вежливым;
* ориентированным на решение проблемы;
* без конфликтного тона.

Плохо:

```
Мы сделали все правильно.
```

Хорошо:

```
Понимаю ваше беспокойство. Давайте уточним, какие моменты нужно скорректировать, и найдем оптимальное решение.
```

# Оценка качества

После обучения проверить папку:

```

```

* classification_report.txt — основные метрики качества.

# Задача датасеттистов

1. Расширять датасет.
2. Проверять правильность категорий.
3. Добавлять реальные варианты сообщений клиентов.
4. Добавлять качественные варианты ответов.
5. Следить, чтобы категории не пересекались.

Главная цель:

Создать датасет, который позволит AI Assistant понимать реальные переговоры между дизайнером и клиентом.
 и 3D-визуализации.

В дальнейшем система будет расширена модулем формирования ответов клиенту.
